### ERROR: Locked notes are not exportable in additional access mode. Please follow this workaround:
  1. Revert back to basic access via File menu, File > Revoke additional access.
  2. Unlock your locked notes and export.
  3. Once export is done, grant additional access from File menu to return to faster mode of exporting.

If this note is wrongly listed as locked note, please update the title of the note in Notes app and
try exporting again. If that doesn't work please reach out to me via Help menu Help > Contact developer.
